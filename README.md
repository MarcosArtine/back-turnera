## Descripción del proyecto

Este proyecto consiste en una aplicación web para la gestión de turnos médicos. Permite administrar la información de pacientes, profesionales y turnos mediante una API desarrollada con Node.js y Express.

La aplicación utiliza archivos JSON como fuente de datos y Pug como motor de plantillas para generar las vistas de la interfaz web. También incluye rutas y controladores separados para organizar las operaciones de cada recurso.

## Tecnologías utilizadas

- Node.js
- Express
- Pug
- Archivos JSON

## Recursos principales

- **Pacientes:** gestión de los datos de los pacientes.
- **Profesionales:** gestión de los profesionales y sus especialidades.
- **Turnos:** consulta y gestión de los turnos médicos.
